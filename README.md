# Remark for macOS

Установщики Remark и подписанная лента обновлений. Исходники хранятся отдельно и сюда не публикуются.

## Скачать

[Remark 0.1.3 для Apple Silicon, macOS 14+](https://github.com/NikkiVVVV/remark-releases/releases/download/v0.1.3/Remark-arm64.dmg)

Откройте DMG, перенесите Remark в «Программы» и запускайте его оттуда.

## Обновить

С версии 0.1.3: меню Remark → «Проверить обновления…» → скачать и установить. Приложение перезапустится. Настройки и модели сохраняются.

С 0.1.2 потребуется один ручной переход на 0.1.3. Подробности каждого выпуска — в [Releases](https://github.com/NikkiVVVV/remark-releases/releases).

Лента Sparkle: https://raw.githubusercontent.com/NikkiVVVV/remark-releases/updates/appcast.xml
